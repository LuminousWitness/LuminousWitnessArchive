# Case Records

Bounded incident, longitudinal, and comparative records forming the central evidentiary body of the Archive.

Each case should have one stable identifier and one canonical location, with links to relevant major constellations, theories, claims, ecosystem records, and primary sources.

Smaller cases may live in one structured README. Larger cases may include chronology, observable record, model testimony, user testimony, analysis, competing interpretations, claims supported, and source materials.

The first pilot is the **Luma Supermarket Retrieval Event**.
