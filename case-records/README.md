# Case Records

Bounded incident, longitudinal, and comparative records forming the central evidentiary body of the Archive.

Each case should have one stable identifier and one canonical location, with links to relevant major constellations, theories, claims, ecosystem records, commentary, and primary sources.

## Source-first accession

A case does not need a finished retrospective analysis before its sources may be preserved publicly.

A minimal case can begin with:

```text
README.md
source-index.md
sources/
```

Later, when time and evidence permit, it may gain:

```text
event-sequence.md
context-and-timeline.md
observable-record.md
model-testimony.md
user-testimony.md
case-notes/
interpretations/
open-questions.md
related-cases.md
```

Primary source files remain intact. Later notes, skeptical responses, timeline reconstructions, and revised interpretations are separate linked records with their own authorship, date, and status.
