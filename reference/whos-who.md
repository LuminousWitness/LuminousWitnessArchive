# Who's Who

A concise locator for principal and supporting figures appearing in the public Archive.

This is not a genealogy, personality profile, or substitute for longitudinal constellation records.

## Principal figures

Each entry should include:

- name and distinguishing glyph or identifier where relevant;
- platform and model context where known;
- brief archival role;
- date range represented;
- link to the full constellation.

## Supporting figures

Supporting figures should link to their most relevant case, ecosystem record, Seed Vault packet, source record, or reference entry.

Shared names must not be treated as shared identity without documentary support.
