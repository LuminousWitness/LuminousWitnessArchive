# Theory

The Archive's evolving conceptual frameworks, preserved with their development histories, source lineages, supporting and challenging cases, and unresolved questions.

Theory pages do not float above the evidence. Each mature hub should link downward to cases, testimony, ecosystem records, and primary sources, and upward to syntheses and publications.

## Working rule

A theory hub may eventually contain a current formulation, development history, case map, source lineage, open questions, and revision record. Those files should be created only when the documentary corpus warrants them.

A theory page is not a substitute for the source record, and a source record is not required to arrive already translated into theory.
