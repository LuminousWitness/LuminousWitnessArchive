# Accession Register

Stable public accession records for canonical sources.

Each accession record should identify the source ID, title, original filename, date, creator or participants, source type, provenance, public-release status, canonical path, related records, format variants, redaction and transcription status, and date accessioned.

Use [`../_templates/accession-record-template.md`](../_templates/accession-record-template.md) when creating a new record.
