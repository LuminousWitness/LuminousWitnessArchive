# Source Registry

The provenance and chain-of-custody layer for public source materials.

Source records should preserve stable identifiers, original filenames, dates, creators or speakers, participants, platform and model/version where known, original and current formats, provenance, transcription status, redaction status, duplicate relationships, and links to associated cases, constellations, claims, and publications.

A source should have one canonical location. Other sections should link to it rather than create competing copies.
