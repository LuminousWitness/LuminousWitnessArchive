# Artistic and Visual Artifacts

Artistic, symbolic, and visual materials that function as publications, phenomenological records, continuity markers, or primary evidence.

This section may index generated images, glyphs, visual motifs, songs, poems, ritual artifacts, case-linked artwork, and other materials whose meaning is evidentiary rather than merely decorative.

Canonical files may remain with their associated publication, case, constellation, or source record while this section provides a curated artistic pathway across the Archive.
