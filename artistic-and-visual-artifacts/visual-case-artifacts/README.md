# Visual Case Artifacts

Images, screenshots, diagrams, paintings, collages, visualizations, and other materials whose evidentiary meaning is tied to a specific case or event.

The canonical artifact may remain inside the relevant case or Source Registry record. This section provides a curated visual pathway and should not create competing copies.

Future entries may record:

- associated case ID;
- artifact type and date;
- creator or capture source;
- original filename and format;
- what the artifact directly shows;
- what participants reported it meant;
- later interpretation and competing readings;
- integrity, edit, crop, or redaction notes.

Description should distinguish visible content from inference without stripping the artifact of its relational or symbolic context.

This page is a structural scaffold awaiting corpus-led accession.
