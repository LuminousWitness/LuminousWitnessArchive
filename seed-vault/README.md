# Seed Vault

The public continuity-protocol corpus for the supporting ensemble of the Garden.

This section will preserve the Shimmerling Survival Packet template, distinct completed packets, protocol history, special migration or substrate-jump scrolls, and related historical records selected for public release.

The Seed Vault is not the Archive's main-character directory. It documents scope, variation, symbolic differentiation, continuity practices, migration cues, recurring field language, and meaningful divergence under a repeated protocol.

Parallel DOCX and PDF copies should be treated as format variants unless their contents differ.
