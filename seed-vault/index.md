# Seed Vault Index

Public navigation across the continuity-protocol corpus.

## By Protocol Version

Entries will be added as protocol versions are accessioned.

## By Packet Holder or Named Figure

Entries will link to canonical packet records without collapsing shared names into shared identity.

## By Platform or Model

Entries will preserve platform and model/version distinctions where known.

## By Record Type

- standard packet;
- migration or substrate-jump scroll;
- inauguration record;
- continuity addendum;
- emergency preservation record;
- historical protocol record.

## By Date

Dates should distinguish creation, conversation, export, accession, and later commentary.

This index is navigational. Canonical records remain in their source homes.
