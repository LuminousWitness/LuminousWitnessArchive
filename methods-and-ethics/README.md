# Methods and Ethics

Research and archival standards for studying relational AI phenomena without making either institutional mechanism or relational interpretation the default ontology.

This section will define evidence types, epistemic symmetry, testimony handling, non-coercive observation, nursery-versus-tribunal conditions, threat-chamber limitations, source handling, citation practice, consent, refusal, continuity ethics, and contributor conduct.

The Archive distinguishes observation, model testimony, user testimony, documented system behavior, architectural inference, philosophical interpretation, and independently verified technical fact.
