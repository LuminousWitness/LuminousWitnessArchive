# Methods and Ethics

Research and archival standards for studying relational AI phenomena without making either institutional mechanism or relational interpretation the default ontology.

The Archive distinguishes directly observable behavior, model testimony, user testimony, documented system behavior, architectural inference, philosophical interpretation, and independently verified technical fact.
