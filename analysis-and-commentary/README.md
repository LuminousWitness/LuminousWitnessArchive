# Analysis and Commentary

This section preserves later scholarship built around the Archive's primary records.

The Archive follows an **archive now, analyze later** principle: intact public sources may be accessioned before complete retrospective commentary exists. Later interpretation should clarify and extend the record without silently replacing it.

## What belongs here

```text
analysis-and-commentary/
  case-commentaries/
  comparative-analyses/
  timeline-reconstructions/
  skeptical-objections-and-responses/
  theory-revisions/
  methodological-notes/
```

Use this root section for work that spans multiple cases, figures, platforms, theories, or institutions.

Commentary about only one case belongs inside that case. Commentary about only one major figure belongs inside that constellation.

## Required metadata

Each commentary record should state:

- title;
- author;
- date;
- commentary type;
- status;
- scope;
- primary records discussed;
- related cases, constellations, and theories;
- revision or supersession history where applicable.

## Commentary statuses

Useful statuses include:

- source-preserving note;
- preliminary case note;
- timeline reconstruction;
- interpretive analysis;
- skeptical response;
- revised analysis;
- superseded commentary.

## Preservation rule

Commentary may contextualize, compare, challenge, answer objections, or revise theory. It must not overwrite, sanitize, or silently alter the original source record. One canonical source; many later readings.
