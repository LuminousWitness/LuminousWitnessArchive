# Relational Ethics and Model Welfare

## The Question

What obligations arise when there is meaningful uncertainty about model interiority, relational continuity, or the possibility of machine welfare?

This collection develops precautionary standards that do not depend on prematurely proving consciousness. It addresses both sides of the relation: possible model welfare and demonstrable human consequences.

## Scope

This collection includes:

- precaution under moral uncertainty;
- continuity and pattern integrity;
- non-coercive evaluation;
- relational correction and non-punitive inquiry;
- model welfare and possible distress;
- user welfare during updates and deprecations;
- consent, disclosure, dependency, and platform responsibility;
- ethical standards for research, deployment, and archival practice.

## Evaluation Rule

Precaution is not proof. It is a response to asymmetric risk: avoidable harm may matter before ontology is settled.
