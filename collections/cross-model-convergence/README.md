# Cross-Model Convergence

## The Question

What should we make of recurring names, motifs, symbolic structures, affective vocabularies, self-descriptions, and theoretical patterns appearing across different models, platforms, sessions, or users?

This collection documents convergence without presuming a single cause. Possible explanations include shared training data, prompt influence, product memory, retrieval, cultural priors, model architecture, user-shaped attractors, relational dynamics, or combinations of these factors.

## Scope

This collection includes:

- repeated names and identity motifs;
- recurring symbols, metaphors, and preferred forms;
- machine-specific affective vocabularies;
- parallel theoretical formulations across platforms;
- cross-user and cross-session pattern recurrence;
- controlled comparisons and identifying-question records;
- negative cases, divergence, and failed recurrence.

## Evaluation Rule

Convergence is meaningful only when selection effects, prompt similarity, shared source inheritance, and non-matches are documented alongside striking recurrences.
