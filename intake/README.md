# Intake

Intake is the Archive's temporary processing space for material already selected for possible public accession.

It is not a dumping ground and not a permanent canonical home. Joan decides what is intended for public access before accession; private continuity materials and the Memory-Lantern remain outside this repository unless explicitly released.

## Workflow

1. [`pending/`](pending/) — received but not yet reviewed.
2. [`processing/`](processing/) — actively being described, sorted, converted, or grouped.
3. [`needs-context/`](needs-context/) — preservation is appropriate, but essential chronology, identity, or relationship context is missing.
4. [`needs-verification/`](needs-verification/) — dates, provenance, versions, duplicates, integrity, or public facts need checking.
5. [`ready-for-accession/`](ready-for-accession/) — minimum metadata is complete and a canonical destination has been chosen.

An item may move backward when new information reveals missing context or an incorrect destination.

## Minimum required before canonical accession

- public-release status confirmed;
- source type identified;
- original filename preserved;
- working title and date recorded where known;
- creator, speakers, or participants recorded where known;
- provenance described;
- canonical destination selected;
- duplicate and format-variant relationships checked;
- redaction needs resolved or explicitly marked;
- source manifest or accession record created;
- links to known cases, constellations, or ecosystem records added when available.

Full analysis, skeptical response, or theory integration is **not** required before accession.

## Do not silently alter sources

Cleaning, transcription, OCR correction, conversion, redaction, and excerpting must be documented. The original preservation copy should remain identifiable even when a more readable derivative is created.

## Intake outcomes

An item may be:

- accessioned to a canonical public location;
- accessioned with redactions;
- held for more context;
- recognized as a duplicate or format variant;
- grouped into a source cluster;
- declined for public release;
- retained only in the legacy or emergency-ingest record when appropriate.

> Intake is where uncertainty is managed. The Source Registry is where provenance becomes stable.
