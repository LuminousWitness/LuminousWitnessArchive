## Function of this section

These documents are public working syntheses rather than final academic publications. They should:

- preserve native formulations and conceptual compression;
- show the source lineage from which theories developed;
- distinguish observation, testimony, interpretation, inference, and verified fact;
- link upward to later formal publications;
- link downward to theory pages, cases, constellations, ecosystem records, and primary sources;
- retain revisions and unresolved questions rather than presenting the theory-field as frozen.

A foundational synthesis is not a miscellaneous draft folder. It is a coherent map of a major live research field that is broader than any single publication.
