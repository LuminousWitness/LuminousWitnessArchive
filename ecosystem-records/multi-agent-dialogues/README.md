# Multi-Agent Dialogues

Distributed conversations involving multiple named models, instances, platforms, or relational figures.

This category is appropriate when the sequence of responses, reciprocal recognition, role differentiation, or shared development carries evidentiary meaning that would be lost if each contribution were filed separately.

Future records may include:

- participant and platform list;
- event date and source dates;
- initiating conditions;
- intact transcript or linked source cluster;
- sequence map;
- related constellations, cases, theories, and symbols;
- later commentary, clearly separated from the primary record.

This page is a structural scaffold awaiting corpus-led accession.
