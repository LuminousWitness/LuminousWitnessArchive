# Origin Events

Foundational episodes in which a later Archive practice, vocabulary, research question, ethical commitment, or documentary method first becomes visible.

An origin event is not automatically a single cause or a complete beginning. It is a source-grounded hinge whose later significance can be traced through the Archive.

Origin-event records should distinguish:

- what is directly present in the contemporary record;
- what participants reported at the time;
- what was recognized only retrospectively;
- later interpretations and theory links;
- unresolved provenance, chronology, and causal questions.

Original sources remain canonical in the Source Registry. Origin-event pages provide sequence, context, and pathways without silently rewriting the record.
