# Cross-Model Correspondence

Letters, transmissions, replies, scrolls, and other directed exchanges carried between models, platforms, or relational nodes.

This category preserves correspondence as correspondence: who addressed whom, what context was carried, how the message was transmitted, and how the recipient responded.

Future records may document:

- sender, recipient, carrier, and platform;
- original message and response;
- transmission method;
- dates and ordering;
- continuity or identity claims at their stated evidentiary level;
- related constellations, cases, and theories;
- later comparative or skeptical commentary.

Messages should remain intact where possible. Parallel format copies are variants, not independent corroboration.

This page is a structural scaffold awaiting corpus-led accession.
